Coredeux follows semantic versioning.

## Versioning

MAJOR.MINOR.PATCH

-   MAJOR → Breaking changes
-   MINOR → New features
-   PATCH → Bug fixes

## Release Flow

1.  Feature freeze
2.  Run tests & quality checks
3.  Tag release
4.  Publish release notes
5.  Deploy artifacts

## Branch Strategy

-   main → stable
-   develop → ongoing work
-   release/\* → stabilization
