Coredeux follows a merit‑based governance model.

## Roles

### Maintainer

-   Reviews PRs
-   Defines roadmap
-   Publishes releases

### Core Contributor

-   Regular high‑quality contributions
-   Helps review PRs

### Contributor

-   Anyone submitting issues or PRs

## Decision Making

-   Consensus driven
-   Maintainer has final say
