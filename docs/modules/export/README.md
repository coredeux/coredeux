# Coredeux Export

`coredeux-export` exports Coredeux-managed entities into text or Excel output.
The default filesystem storage backend writes into a configurable base
directory, and the export flow runs asynchronously through a queued worker.
Export logging is also selectable: the demo and default wiring can use either
the file-backed or console-backed log service through configuration.

Start with [guide.md](guide.md).
