`coredeux-core-jdbc` provides a direct SQL / JDBC-backed implementation of
`CoredeuxDataAccessService`.

Use it when you want relational storage without JPA. The adapter works with
plain SQL, `NamedParameterJdbcTemplate`, and Spring-managed data sources.

Open the full reference in [reference.md](reference.md).
