This section documents the import-file parsers that now live inside
`coredeux-import`.

- [Import Parser Guide](guide.md)

The parser package provides:

- `CoredeuxTextImportParser` for pipe-separated import text.
- `CoredeuxExcelImportParser` for XLS/XLSX workbooks where each cell maps to
  one import cell.
